This is a lightweight in-browser workspace for loading, viewing, and instrumenting web content in an isolated sandbox. Content is fetched, transformed, and rendered entirely client-side, so you can inspect how pages behave and experiment with your own snippets.

Browser

Enter an address in the box above to load a page in the sandbox.
All traffic is end-to-end encrypted with TLS.

Requests

You can inspect every request the workspace makes, and the transformations applied to it, in the requests tab.
Note that requests will not be captured until you first click on the requests tab.

Playground

The playground lets you write your own html/css/js snippets which run inside the sandbox. Your files are "served" from a fake origin, which can be configured to be any URL. Notice that if you add a console.log(location.href) in your code, the page will really be running on the fake origin.
